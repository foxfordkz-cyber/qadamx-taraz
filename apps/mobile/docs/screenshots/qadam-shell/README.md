# Компьютерные снимки UI, 2026-10-16

Код приложения `f9651a3`, 390×844. Снимки получены из Flutter widget renderer
на Windows с явно синтетическим `ShellFixture`; реальный API не вызывался.
Жёлтая полоса на каждом изображении отмечает происхождение. Это не Android,
не вход A/B и не видео живого сценария.

- `business-ru-fixture.png`: условная учебная точка из GET /me fixture и web-действия.
- `market-ru-fixture.png`: существующий Мал базар, пустая синтетическая выдача.
- `profile-kk-fixture.png`: KZ, профиль и объяснение отдельной браузерной сессии.

QA harness находится локально в игнорируемом `build/qa_preview_test.dart` и
использует `test/support/shell_fixture.dart`. Для чтения кириллицы/KZ в renderer
загружен установленный Windows Segoe UI; font-файл в репозиторий/APK не копировался.
В приложении сохраняется обычная системная Material типографика.
