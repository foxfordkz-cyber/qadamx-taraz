  Flutter с синтетическим MockClient. Исходник APK0.5.2:
  `79a29b9341b03e4ac3ffc58ebf6a06b00374d2f4`.

## Воспроизведение и монтаж

Сначала скачайтеMP4 целиком. Откройте в обычном видеоплеере и включите полный экран.
Звук отсутствует по заданию. На сцене достаточно самого ролика; субтитры уже вшиты.

Исходники: `build_video.py`, `storyboard.json`, `captures/`, `fonts/`,
`native-clip.mp4`, `Qadam-Demo-RU.srt`. В репозитории короткая запись эмулятора
лежит в `sources/native-clip.mp4`; скрипт поддерживает оба расположения.

Для повторного экспорта нужны Python3, Pillow, numpy, OpenCV, fontTools,
imageio-ffmpeg. Скрипт использует только включённые локальные ассеты;
не обращается кAPI и не меняет приложение.

```text
python build_video.py --preview
python build_video.py
python verify_video.py
```

Выпуск видео не изменяет APK и не закрывает незавершённую физическую приёмку приложения.
