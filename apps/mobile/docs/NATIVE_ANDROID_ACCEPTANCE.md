## Короткий проход (учебные точки и данные)

1. Установить APK поверх предыдущего Qadam, не очищая данные. Открыть приложение,
   проверить RU/KZ и клавиатуру на маленьком экране. Зафиксировать модель/Android.
2. Войти A, выбрать собственную учебную точку из `/me`. Сверить главную с кабинетом:
   продажи/поступления за серверный день, общий долг за всё время, новые заявки.
   При ошибке должна быть ошибка с повтором, а не выдуманные нули. Открыть HTTPS-кабинет;
   отдельный вход в браузере допустим. Пароли вводить только на устройстве.
3. Создать клиента «Учебный Android <время>». Записать продажу **1 000,50 ₸**,
   получено **400 ₸**, выбрать этого клиента. Предпросмотр ещё ничего не записывает.
   Подтвердить: ровно одна продажа, долг **600,50 ₸**. Через «Долги» выбрать её и внести
   доплату **600,50 ₸**: долг 0; продажи не увеличились, поступления увеличились.
4. На отдельном согласованном учебном действии проверить потерю сети после отправки.
   Не создавать новый запрос. Перезапустить приложение, войти тем же аккаунтом/выбрать
   ту же точку и открыть восстановление: повторяются исходные данные, дубля нет.
   Для клиента `not_observed` не разрешает новый ключ. Проверить и поздний ответ после выхода.
5. Logout A → вход B: только разрешённые B точки и приватные данные; нет pending A.
   Вернуться A: его незавершённое действие можно восстановить. Сессия браузера отдельная.
6. В Мал базаре выбрать фото/снять учебное фото → форма → предпросмотр → явная публикация.
   Сверить «Мои», фильтр рынка, «Есть сегодня», затем «Продано»: запись исчезла из общей
   ленты, осталась владельцу, приватное фото открывается. Null-минимум — «Нет данных».
   Фото не должно создавать операцию в денежном журнале. Отказ камеры не закрывает форму.
7. Перезапустить без logout: сессия восстановлена, данные получены с сервера; точку
   после холодного запуска выбрать заново. Открыть аналитику 7/30, каталог и заявки.
   Null среднего чека — «Нет данных»; отрицательные поступления не обнуляются.
8. Проверить микрофон локально: отказ → ручной текст; разрешение → запись → стоп →
   прослушивание → удалить/перезаписать; уход в фон завершает запись. Стоп не отправляет
   аудио. **«Получить AI-черновик» пока не нажимать: платный тест отдельно не разрешён.**

После отдельного согласования бюджета возможен один новый целевой AI-тест: запись WAV
с фразой «Продал учебному клиенту товар на 1500 тенге, получил 1000 тенге»;
ожидаются total=150000, received=100000 тиын, долг 50000 только после явного выбора клиента
и подтверждения. Сначала проверить/исправить черновик; не запускать повторы автоматически.
Это новая запись, она не закрывает старый инцидент recording.webm.
