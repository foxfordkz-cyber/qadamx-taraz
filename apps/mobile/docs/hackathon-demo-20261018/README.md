18 октября 2026. 90 секунд, 1920×1080, 24 fps, MP4/H.264, без звука.
[Скачать MP4 без входа](https://github.com/foxfordkz-cyber/qadamx-taraz/releases/download/qadam-hackathon-demo-20261017/Qadam-Business-Demo-RU-90sec.mp4).
Русские субтитры вшиты. В описании и в кадрах один и тот же учебный пример:
продажа **4 500 ₸**, получено **2 000 ₸**, долг **2 500 ₸**;
доплата **500 ₸**, остаток **2 000 ₸**.

Это короткий монтаж сохранённых интерфейсов с плавными переходами и поясняющими
карточками. Он **не является непрерывным живым прогоном** и не подтверждает
физическую приёмку Android. Исходный трёхминутный ролик с озвучкой не изменён.

## Источники и ограничения

- Основа — проверенные кадры трёхминутного ролика от 17 октября 2026 из
  `apps/mobile/docs/hackathon-demo-20261017`. Геометрия площадок и учебные точки
  не изменялись. Это сохранённые кадры, не заявление о текущем runtime SHA сайта.
- AI-ввод и черновик — сохранённый синтетический интерфейс из
  `docs/screenshots/presentation-polish/sale-draft-390.webp`.
  Он уже содержит 4 500 / 2 000 ₸. Пример 3 000 / 1 000 / 500 ₸ из нового ТЗ
  к этим кадрам не приписывается; описание исправлено по фактическому материалу.
- Долги/история — настоящая отрисовка Flutter с синтетическими данными из
  `apps/mobile/docs/reports/visual-052`. Их отдельное происхождение подписано.
- Аналитика — встроенное Demo опубликованного сайта; не реальные показатели продавца.
- Не выполнялись платные AI-вызовы, денежные записи, отправка заявок,
  изменение общей БД, Auth, deployment или memberships.
- Новый помощник «Спросите Qadam» не показан: его deployment не подтверждён.
  Дополнительный 30–40-секундный фрагмент требует сначала подтверждения выпуска.
- Manrope и Noto Sans используются из локальных ассетов проекта; лицензии OFL
  находятся рядом с исходными шрифтами. Сторонняя музыка и голоса не добавлялись.

## Проверки и публикация

`video-verification.json` содержит фактические размер/SHA256, параметры,
полное декодирование, 11 контрольных кадров и распознанный финальный QR.

GitHub Release используется как доступный запасной канал. Публикация на
YouTube/Google Drive и проверка ссылки в режиме инкогнито **не выполнены**:
автоматическая проверка разрешений отклонила доступ к браузерной сессии Drive,
не признав его явно разрешённым. Файлов в Drive не создано, отказ не обходился.

Скачивание без входа проверяется отдельным HTTP-запросом без cookies и токенов;
результат фиксируется в `public-download-verification.json`. Это проверка
анонимного скачивания, а не проверка Drive/YouTube-плеера.

Просмотр на физическом телефоне **не выполнен**.

## Повторный экспорт

Рендер не обращается к API. Нужны Python 3, Pillow, numpy, OpenCV,
fontTools, imageio-ffmpeg. Чтобы ограничить память, используется экспорт
одной сцены за раз с одним потоком FFmpeg:

В репозитории кадры, шрифты/OFL и исходная короткая запись переиспользуются
из `../hackathon-demo-20261017/` без изменения тех файлов.
В переносимом ZIP они лежат в локальных `captures/`, `fonts/` и `native-clip.mp4`.
Скрипты сами выбирают существующее расположение; абсолютные пути не нужны.
Команды ниже выполняются из папки этого ролика. FFmpeg берётся из
`imageio-ffmpeg`; не требуется путь к конкретной установке на ПК автора.

```text
python build_video.py --preview
python export_low_memory.py
python verify_video.py
```

Не запускать обычный `build_video.py` без `--preview` на ограниченном по памяти
компьютере: первый покадровый экспорт прервался MemoryError. Финальный файл
собран отдельно и проверяется целиком.
