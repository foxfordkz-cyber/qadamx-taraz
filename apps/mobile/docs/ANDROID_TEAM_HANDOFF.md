## Шесть шагов

1. **Установка и запуск.** Скачать APK на телефон, открыть загрузку и следовать
   запросу Android об установке. Если требуется разрешение установки, выдать его
   приложению, через которое открывается этот APK. Запустить Qadam: видны
   «Мой бизнес / Мал базар / Профиль», лента загружается либо честно показывает
   пустой результат. При USB можно использовать `adb install -r qadam-0.2.2-96ef1c4-debug.apk`.
   При ошибке установки записать её текст; не удалять старое приложение/его данные
   ради обхода ошибки, поскольку там могут быть незавершённые намерения.

2. **A → точка → кабинет.** В «Профиль» войти как A, открыть «Мой бизнес», выбрать
   одну из доступных точек. Нажать «Открыть кабинет»: открывается системный браузер
   с HTTPS `/seller` или страницей входа. Отдельный вход A в браузере допустим;
   точка в кабинете выбирается отдельно. Вернуться в Qadam — приложение работает.

3. **Выход A → вход B.** Выйти A в приложении, войти B. В «Мой бизнес», «Мои» и
   приватных формах нет точек, выбора, черновиков и объявлений A; загружаются данные B.
   Публичная лента может показывать сегодняшние публичные объявления A — это ожидаемо.
   Сессия браузера независима: выйти A также на сайте, если кабинет будет проверяться
   под B. Выход из Flutter не означает выход из браузера.

4. **Фото → учебная публикация под B.** Снять лист «Учебное фото» камерой и выбрать
   безличное изображение из галереи; если проверен только один источник, второй
   отметить непроверенным. До трёх фото, каждое до 8 MiB. Заполнить: овца, 2 головы,
   **30 000 ₸ за голову**, место «Учебная проверка Android», рынок
   «Учебный рынок Android <дата-время>», контакт «Учебный тест, связи нет».
   Дать согласие на публикацию контакта. В предпросмотре проверить фото/сумму,
   затем явно опубликовать. После подтверждения сервера — одна запись в «Моих» B
   и публичной ленте, с учебной пометкой. Сохранить ID записи, если он доступен;
   иначе записать уникальный рынок и время. Не считать нажатие кнопки успехом.

5. **Рынок → Есть сегодня → Продано.** В ленте применить вид/место/уникальный рынок:
   найдена опубликованная запись. В «Моих» B подтвердить «Есть сегодня», обновить
   ленту — та же запись без дубля. Затем нажать «Продано» и дождаться ответа.
   После обновления её нет в публичной ленте; в «Моих» с фильтром «Продано» она
   остаётся, собственное фото открывается. Учебная статистика может быть пустой:
   minimum=null отображается как «Нет данных», не как ноль.

6. **Перезапуск без выхода.** Оставаясь под B, закрыть Qadam из списка недавних
   приложений и открыть снова, не очищая данные. Вход B восстановлен без пароля;
   в «Моих» → «Продано» сохраняется та же запись, её поля и фото; данные A не появляются.
   Точки B загружаются заново. Выбранную точку после холодного запуска может
   потребоваться выбрать снова — выбор хранится в памяти, это текущее поведение.
   Восстановление сессии не доказывает проверку автоматического refresh: его
   отмечать только при отдельном наблюдении. Выйти после фиксации результата.

Если результат публикации неизвестен, сохранить форму/pending и повторять только
исходное действие; не создавать ещё одно объявление для обхода ошибки. Сообщить
номер шага, время и безопасный текст ошибки. Учебную запись завершить «Продано»;
если завершение не удалось, явно указать оставшуюся активную запись в отчёте.

| Поле | Сейчас / значение участника |
|---|---|
| Участник | Не указан |
| Производитель и модель телефона | Не предоставлены |
| Версия Android | Не предоставлена |
| Дата, время, часовой пояс | Физический прогон не начат |
| Сеть (Wi-Fi / мобильная) | Не указана |
| APK | 0.2.2+5, commit 96ef1c42ba341dc9fcdc6539d9ee499ab797c178 |
| Backend по передаче команды | API 0.6.2, commit e699158b5238285fb02c85bc5d92c45a3cc4ca84 |
| Рынок и ID учебной записи / время публикации | Не создавались на устройстве |

Заменять «НЕ ПРОВЕРЕНО» на PASS / FAIL / BLOCKED только после наблюдения.
В последней колонке описать увиденное, время и ссылку на безопасный скриншот/видео.

| Шаг | Результат | Фактическое наблюдение |
|---|---|---|
| 1. Установка и запуск | НЕ ПРОВЕРЕНО | Android в текущей сессии не подключён |
| 2. A, выбор точки, кабинет | НЕ ПРОВЕРЕНО | Результат участника не получен |
| 3. Выход A, вход B, изоляция | НЕ ПРОВЕРЕНО | Результат участника не получен |
| 4. Фото и публикация B | НЕ ПРОВЕРЕНО | Камера: —; галерея: —; ID/рынок: — |
| 5. Фильтр, Есть сегодня, Продано | НЕ ПРОВЕРЕНО | Итоговый статус записи: — |
| 6. Перезапуск, сессия и данные | НЕ ПРОВЕРЕНО | Восстановленный аккаунт/ID: — |

Для совместного прохождения прислать сначала модель, Android и результат шага1;
при ошибке — остановиться на этом шаге и передать наблюдение. Пароли, JWT, IMEI,
серийный номер и содержимое личных уведомлений в протокол не включать.
Короткое видео 60–90 секунд можно снять после входа, без формы пароля.
