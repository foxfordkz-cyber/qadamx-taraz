# Настоящий Android-прогон Qadam 0.5.1+10

Source: `640d0ef7c936a403162a8c7185f2438ca6679bba`.
Официальный изолированный Android SDK эмулятор, Android7.0/API24/x86_64,
1080×1920/density420 (около411dp), системный font_scale явно не задан.
**Не физический телефон.** Данные публичного Render API; синтетической подмены в APK нет.

Обновление0.5.0+9 → 0.5.1+10 выполнено с `install -r`, без удаления приложения/данных.
