# Граница встроенного 3D

Площадки, фильтры, магазины, каталог, заявки, Auth и кабинет — Flutter-экраны.
WebView используется только как локальный WebGL canvas для принятого GLB:
Flutter не имеет штатного glTF renderer; Three.js той же версии0.186.1, что
актуальный сайт, сохраняет материалы и сцену без конвертации моделей.

- Модели, previews и manifest побайтово скопированы из `apps/web/public` на
  main1a541ef. `assets/venues/asset-provenance.json` содержит SHA256 каждого файла.
  Источники/ограничения моделей остаются в upstream `apps/web/public/asset-sources.md`.
  Идентификаторы и геометрия не менялись; согласование новых моделей не требуется.
- JS бандл собран локально из `tool/venue_viewer` (npm ci; npm run build);
  сохранены lock-файл и MIT license Three.js. CDN/удалённый JS не используется.
- WebView получает GLB через небольшие сообщения из Flutter assets, а также
  только публичные name/id/slug уже загруженных магазинов. Нет Supabase client,
  cookies, токенов, HTTP API, формы или кабинета внутри WebView.
- CSP запрещает сеть/worker/frame; навигация разрешена только `about:blank`.
  Bridge принимает ready/loaded/error/select; selection содержит hotspot ID.
  Flutter сверяет hotspot→business_id→slug и venue_id с API перед нативным переходом.
  Неизвестный/несогласованный маркер ничего не открывает.
- Сцена одна. Ограничены zoom, pan, наклон и pixel ratio. Камера учитывает ширину
  viewport; reset возвращает общий вид. Видимый маркер26px внутри кнопки48px; описание жестов RU/KZ.
  Режим «Управлять3D» включается явно; до него страница принимает прокрутку.
  Высота210–320dp. Poster виден при загрузке/ошибке и не дублирует работающую модель.
- При уходе в фон rendering приостанавливается; при dispose удаляются ресурсы.
  Timeout/отсутствие WebView/WebGL/context loss дают нативный текст, poster и список.
  Список магазинов не зависит от renderer и доступен также при ошибке manifest.

Наличие renderer и статическая проверка не доказывают производительность на
телефоне. Поворот, zoom, touch, чтение списка, соответствие всех9точек и возврат
из магазина требуют отдельной физической приёмки. Изображения/схема не обещают
точный маршрут к настоящему продавцу; учебные магазины маркируются из API.
