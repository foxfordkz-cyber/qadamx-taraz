## Если установка снова отклоняется

Не удалять приложение и не очищать данные. Проверить SHA256 скачанного APK,
свободное место и записать точное сообщение Android. При подключённом USB с разрешённой
отладкой использовать `tool/check_android_install.ps1 -ApkPath <APK> -ExpectedSha256 <SHA256> -Install`.
Он делает `adb install --no-streaming -r`, фиксирует модель/Android/старую версию и
код `INSTALL_FAILED_...`, без serial, токенов и логов приложения. Не отключать защиту
телефона, не применять downgrade/uninstall/clear. Скриншот0.3.0 остаётся известным
FAIL; физическое обновление новым APK пока не подтверждено. Капитан проверил0.4.0
на отдельном эмуляторе; это не проверка обновления телефона.

Протокол заполнить фактами: модель/Android/участник/время, APK hash, source commit,
старый→новый versionCode, PASS/FAIL по каждому шагу, точная ошибка и ограничения.
Видео физической приёмки — только после физического прогона, без паролей/личных клиентов/секретов.
