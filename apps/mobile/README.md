# Qadam · Мал базар (Flutter / Android)

Клиент общего FastAPI. Каталог не подменяется mock-данными при ошибке сети.
Supabase SDK обслуживает существующую авторизацию, восстановление и refresh.
Android — текущая платформа поставки; iOS/Web проект не создавался.

## Запуск

Нужны Flutter stable (Dart >=3.11), JDK 21 и Android SDK. Точные проверенные
версии и результаты сборки указаны в `../../docs/handoffs/mobile.md`.

1. Получить у backend достижимый FastAPI URL и публичный ключ проекта. URL
   Supabase не является URL FastAPI. Чужой localhost не подходит.
2. Скопировать `config/public.example.json` в игнорируемый
   `config/public.local.json`; заполнить **только** API_BASE_URL,
   SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY. API URL включает `/api/v1`.
3. Выполнить из `apps/mobile`:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run --dart-define-from-file=config/public.local.json
```

Учебный аккаунт получают отдельно по закрытому каналу и вводят в форме входа.
Пароль, access/refresh token и серверные ключи в конфигурацию не входят.
SDK-сессия сохраняется через `LocalStorage` adapter в `flutter_secure_storage`.
Серверные таблицы и Storage напрямую из приложения не вызываются.

Сборка с проверкой разрешённых публичных параметров:

```powershell
./tool/build_android.ps1 -PublicConfig config/public.local.json
```

Результат: `build/app/outputs/flutter-apk/app-debug.apk` (внутренняя установка,
debug-подпись, не магазин приложений). Без согласованной конфигурации можно
собрать с `config/public.example.json`; такой APK показывает недоступность
подключения и пригоден только для проверки интерфейса, не живого сценария.

HTTP разрешён только Android debug manifest и debug config. Release требует
HTTPS; release-подпись для магазинов не настроена. Для собственного согласованного
LAN API использовать реальный LAN адрес. `10.0.2.2`/`adb reverse` уместны только
для API, запущенного на **этом** компьютере. Клиент сервер не запускает.

## Поведение

- Без входа: сегодняшняя выдача, фильтры/карточка и медиана цен предложений.
- После входа: камера/галерея → multipart `file` → форма → предпросмотр →
  явная публикация; свои объявления, полное редактирование, подтверждение
  «Есть сегодня», «Продано», «Снять».
- Цена за голову хранится как Dart `int` в тиынах. Ввод десятичных тенге
  разбирается без `double`. «Сегодня» определяется ответом сервера.
- До трёх JPEG/PNG/WebP, исходник до 8 MiB. Все фото идут через FastAPI;
  собственные фото читаются с Bearer по приватному маршруту.
- Каждый изменяющий запрос сохраняется **до отправки** с UUID ключом,
  аккаунтом, точным URL и телом. Фото для повтора имеют зашифрованный
  неизменяемый снимок в приватном каталоге приложения. Таймаут/5xx/потеря
  сети сохраняют намерение. Повтор запускается пользователем, с тем же ключом.
- Подтверждённый ответ сохраняется до применения интерфейсом и явного
  acknowledge; перезапуск между ответом и обработкой не создаёт второй запрос.
  Pending другого аккаунта не показывается и не отправляется. Смена API URL
  запрещает повтор старого намерения в новой среде.
- Нельзя начинать новую запись, пока неизвестен результат предыдущей.
  При повреждении защищённого хранилища приложение не удаляет намерение
  молча. Переустановка приложения удаляет локальные данные и не является
  безопасным способом повторить публикацию с неизвестным результатом.

Тесты используют явно синтетические contract fixtures и HTTP-подстановки.
Они не доказывают доступность общей Supabase/API/Storage или физического Android.
Фактическая живая приёмка и ограничения — в mobile handoff.

## Контракт и зависимости

Проверенный backend code commit: `c447a594a6a7d9aad1ee7fca751053bf6a176a61`,
API 0.5.0, `packages/contracts/LIVESTOCK_API.md`, OpenAPI и `examples.json`.
`pubspec.lock` фиксирует разрешённые версии. Android backup отключён, чтобы
сессия/ключи и приватные формы не переносились в резервные копии устройства.

SDK-интеграция следует [Supabase Flutter](https://pub.dev/packages/supabase_flutter),
[secure storage](https://pub.dev/packages/flutter_secure_storage) и
[image_picker](https://pub.dev/packages/image_picker). Доступ к камере/галерее
обрабатывает системный picker; при отказе доступен ручной ввод без фото.
