## Источники доказательств

Источники в таблицах не смешиваются: у каждого своя колонка.

- **[A]** APK 0.5.2 на Android Emulator Pixel 6: Android 16, 1080×2400, 420 dpi (≈411 dp), SwiftShader.
  - Production API только на чтение: без входа, без отправок, форма заявки не заполнялась.
  - Крупный текст: временно `font_scale 2.0` и `wm density 540` (≈320 dp), язык KZ.
  - После проверки возвращены `font_scale 1.0` и исходная плотность 420. Это подтверждено после перезагрузки эмулятора.

- **[C]** Чтение кода `79a29b9` и diff с `640d0ef`.
- **[P]** Физический телефон. У роли №6 его нет, поэтому для всех пунктов — **не проверено**.
