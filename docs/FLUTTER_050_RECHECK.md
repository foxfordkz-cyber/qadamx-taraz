## Что нужно, чтобы закрыть проверку

1. **Исправления P2 в коде.** Ни один из девяти P2 не исправлен ни в `640d0ef`, ни в APK 0.5.1:
   - группа 1 — `crm_charts.dart`: легенда-образец и `#b36d20` для поступлений;
   - группа 2 — отступы и `*` в `InquiryForm`, единый виджет ошибки;
   - группа 3 — сортировка магазинов в `VenuePage` по `pointNumber`;
   - группа 4 — warning-бейдж для учебного, подложка или рамка и пометка у 3D-сцены;
   - группа 5 — ограничение масштаба заголовков: шапка магазина, выбор точки, блок кабинета;
   - ответ по кнопкам «Оставить заявку» и «Отправить заявку».
2. **N1:** вернуть пометку «учебная / адрес не подтверждён» в карточки площадок или поднять сноску.
3. **Повтор [A] на эмуляторе по следующему APK с SHA256.** Кабинет, аналитику и долгие KZ-названия на APK можно проверить только с тестовой учётной записью, которую выдаст интегратор. Учётные данные в этой проверке не вводились.
4. **[P] — не проверено.** Физическую приёмку, включая обновление 0.5.0 → 0.5.1 на телефоне, организует интегратор по Android-чек-листу. Эмулятор её не заменяет. iPhone/Safari не проверялись (#66).
