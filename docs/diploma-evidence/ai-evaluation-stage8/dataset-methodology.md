# Dataset construction and independence limits

Version: qadam-stage8-constructed-holdout-v1. 120 manually specified synthetic input
records, ten categories × four RU, four KK, four mixed. Forty semantic scenario groups
have related multilingual variants; 120 rows are not 120 independent real-world observations.
No merchant conversation, participant, audio recording or personal information was used.

The authoring script imports only Python standard-library modules. It does not import
application code or call an extractor, provider, database or network. Gold values are
author annotations of explicit statements and contract-required clarifications.
Provider replies are also authored, with documented faults in scale, unsupported names,
conflicting payments and malformed JSON. Their distribution is artificial.

New scenarios use multi-sentence context, previous receipts, old debts, price tags,
corrections and cross-business customer contexts. They are not generated by renaming
Stage7 cases. The builder checks zero exact input overlap with Stage7.
Related language variants were deliberately kept; do not treat them as independent samples.

Preparation order: verify fixed Stage7 integration → author protocol and corpus → check
structure/gold arithmetic and fixture serialization only → freeze manifest + Git commit →
run original and improved implementations. Freeze covers JSONL, CSV, protocol and builder
with LF-normalized SHA-256. An authoring-only line-wrap correction before the freeze commit
did not change dataset labels/rows.

**Not blind independence:** the same Codex author knows the Stage7 implementation and
reported weaknesses. The dataset is unseen during Stage7 development, but category selection,
language choices, gold and fault injection can reflect that prior knowledge. There is no
independent annotator or real-world sampling. This is a constructed held-out engineering
benchmark, not unbiased final AI accuracy or independent external validation.

Gold is immutable after the first run. Disagreements must be appended to a separate review
log with original label, proposed alternative, linguistic/contract rationale and independent
reviewer decision. A future version requires a new version/hash and both original and revised
results. No label may be selected because it favors one implementation.

For the diploma: Codex produced code, authored synthetic examples and computed deterministic
metrics. The student must independently interpret limitations and obtain human linguistic
review/consent before claiming real user relevance. No participant study is completed here.
