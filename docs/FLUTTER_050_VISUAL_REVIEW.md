### Откуда снимки

1. **APK на эмуляторе** (`apk/`). Тот же APK установлен на Android Emulator Pixel 6: Android 16, 1080×2400, 420 dpi (≈411 dp), рендеринг SwiftShader. Публичные экраны получали production API только на чтение. Ничего не отправлялось, вход не выполнялся. Кабинет и аналитика без входа недоступны, поэтому в `apk/` есть только экран входа в кабинет.
2. **Рендеры автора** (`render/`) — `apps/mobile/docs/reports/visual-050` @ `7b3a8ba`: настоящие Flutter-виджеты в `flutter test` на синтетических данных. Автор снимал их на `0c3f4a5`; до `7b3a8ba` в `lib/` изменились только `crm_api.dart` и `runtime.dart`, внешний вид не затронут. Из них взяты снимки кабинета, аналитики, состояний и KZ-стресса 320 dp ×2.0.
3. **Сайт** (`site/`): Playwright с установленным Chrome, 390×740 и KZ 360×780.

Flutter SDK на этом ПК нет в `PATH`, своих рендеров из исходников я не делал.

**Эмулятор не заменяет физическую приёмку.** Жесты 3D, FPS и память WebView, обновление поверх 0.4.0, камера и микрофон, реальные шрифты производителя и масштаб текста на телефоне остаются за физической проверкой: её организует Дамир по `ANDROID-CHECKLIST-050.md`. На эмуляторе при первом запуске появился диалог «System UI isn't responding». Это сам эмулятор, а не Qadam: после «Wait» приложение работало.

Полная галерея — [screenshots/flutter-050-review](screenshots/flutter-050-review/README.md).

## Итог

Основа совпадает с сайтом: та же палитра (paper `#f5f3eb`, ink, green `#164c3e`, lime, line, muted), Manrope и локальный Noto для Ғ/Қ/Ң/Ә/Ұ (KZ-глифы на эмуляторе рисуются правильно), радиусы 12/20, отступ страницы 16, кнопки не меньше 48 dp, RU/KZ на всех проверенных экранах. Учебный характер площадок и точек показан: «учебная площадка, адрес не подтверждён», «Учебная витрина/точка», 3D с маркерами 1–3, «Управлять 3D» / «Общий вид». На эмуляторе 3D-сцена Кайкармета загрузилась, все три маркера на месте.

P1 (блокирует показ или вводит в заблуждение) не найдено. Расхождения со стилем сайта — в основном действии, пометках «учебное», рамке 3D, легенде графика и состояниях ошибок.

### Не к mobile

Эти пункты передаются соответствующим владельцам; в этой ветке они не исправлялись.

- **public-web / сайт**: на главной в блоке «Мал базар» всё ещё «Тестовая сборка 0.3.0 … APK 54,6 MiB» и ссылка на `mobile-v0.3.0-native.1`. Обновлять на 0.5.0 только после решения интегратора об Android-приёмке.
- **backend / seed**: описание «Учебная точка, не подтверждённый партнёр площадки.» и товар «Учебный товар» приходят только на русском и в KZ-интерфейсе остаются русскими (apk/07-shop-kk). Названия «Демо Кайкармет food/home/clothes» смешивают языки — это известный пункт VISUAL_AUDIT № 11.

## Что не проверено

- Кабинет, продажа, долги, история и аналитика из настоящего APK: нужен вход, тестовые учётные данные я не вводил. Для этих экранов — только рендеры автора.
- Ширины 320/360 и масштаб текста 1.3/2.0 на эмуляторе: системные настройки эмулятора не менялись, стресс-кадры взяты у автора.
- Жесты 3D, переход по маркеру на эмуляторе, FPS, долгая работа WebView, обновление поверх 0.4.0.
- iPhone/Safari — отдельная задача владельца общего frontend (#66).
