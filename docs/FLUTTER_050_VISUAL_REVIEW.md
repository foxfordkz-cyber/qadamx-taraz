## Доказательства

У каждого замечания ниже стоят метки типа доказательства: **[A]**, **[R]**, **[C]**. Если какая-то часть замечания не проверена, это сказано прямо в строке.

### [A] Проверено в APK на эмуляторе

Тот же APK установлен на Android Emulator Pixel 6: Android 16, 1080×2400, 420 dpi (≈411 dp), рендеринг SwiftShader. Публичные экраны получали production API только на чтение. Ничего не отправлялось, вход не выполнялся. Проверены экраны:

- площадки RU/KZ;
- площадка Кайкармет с 3D: сцена загрузилась, маркеры 1–3 на месте;
- список магазинов площадки;
- магазин RU/KZ;
- форма заявки — только внешний вид, без отправки;
- Мал базар KZ, пустая лента;
- вход в «Мой бизнес» без авторизации.

При первом запуске эмулятор показал «System UI isn't responding». Это сам эмулятор: после «Wait» Qadam работал.

### [R] Просмотрено на рендерах автора

`apps/mobile/docs/reports/visual-050` @ `7b3a8ba`: настоящие Flutter-виджеты в `flutter test` на синтетических данных. Автор снимал их на `0c3f4a5`; до `7b3a8ba` в `lib/` изменились только `crm_api.dart` и `runtime.dart`, внешний вид не затронут. Отсюда взяты:

- главная продавца;
- аналитика и графики;
- продажа;
- состояние ошибки;
- стресс-кадры KZ 320 dp ×2.0.

Это не Android и не эмулятор. Flutter SDK на этом ПК нет в `PATH`, своих рендеров из исходников я не делал.

### [C] Проверено чтением кода

`apps/mobile/lib` @ `7b3a8ba`: тема (`ui/qadam_theme.dart`), общие виджеты, публичные экраны, 3D-viewer, графики. Сравнение с токенами и CSS сайта. В строках указаны пути и строки.

### [N] Не проверено

- Кабинет, продажа, долги, история и аналитика в настоящем APK: нужен вход, тестовые учётные данные не вводились.
- Отрисовка легенды графика на Android: глифы `━`/`┄` проверены только в рендере автора и по коду.
- Ширины 320/360 и масштаб текста 1.3/2.0 на эмуляторе: системные настройки не менялись, есть только рендеры автора.
- Сообщения об ошибках отправки заявки и загрузки в APK: не вызывались, есть только рендер и код.
- Жесты 3D, переход по маркеру, FPS и память WebView, обновление поверх 0.4.0, камера и микрофон.
- Физический Android. **Эмулятор не заменяет физическую приёмку**: её организует интегратор по `ANDROID-CHECKLIST-050.md`.
- iPhone/Safari — отдельная задача владельца общего frontend (#66).

- lime-pill с ink-текстом — только для одного главного действия экрана и только там, где так же сделано на сайте: «Оставить заявку» и «Отправить заявку» на странице магазина, «Продажа» на главной продавца;

## Не к mobile

### Backend: русские описания учебных данных в KZ-интерфейсе

Описание точки «Учебная точка, не подтверждённый партнёр площадки.» и товар «Учебный товар» приходят из seed только на русском. Поэтому в KZ-интерфейсе приложения они остаются русскими [A] — apk/07-shop-kk. Названия «Демо Кайкармет food/home/clothes» смешивают языки (VISUAL_AUDIT № 11).

Это передаётся владельцу backend. В этой ветке seed и БД не менялись.

### Сайт: ссылка на APK 0.3.0

На главной сайта в блоке «Мал базар» по-прежнему «Тестовая сборка 0.3.0 … APK 54,6 MiB» и ссылка на `mobile-v0.3.0-native.1` [A, сайт]. Её меняем отдельным изменением и только после того, как установка и обновление 0.5.0 пройдут на физическом Android.
