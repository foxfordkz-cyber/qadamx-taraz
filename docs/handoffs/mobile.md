## Реализация

Публичные сегодняшние объявления, фильтры и cursor pagination, карточка,
статистика медианы предложений/количества/периода и insufficient_data.
Supabase SDK login/session/refresh/logout, собственные объявления, камера и
галерея, до трёх фото через multipart FastAPI, полная форма/предпросмотр/
явная публикация, редактирование и confirm_today/sell/withdraw. Интерфейс RU/KZ.
Учебные объявления помечаются по is_demo; синтетическая выдача в приложении
отсутствует. Цены — int тиыны за голову; дату определяет сервер.

Pending намерение сохраняется до сети: аккаунт, UUID Idempotency-Key,
исходный URL/JSON; для фото — неизменяемый AES-GCM снимок в private app folder,
ключ в flutter_secure_storage. Повтор только явный, с прежним телом/ключом.
Подтверждённая квитанция хранится до её применения UI. A→B→A и асинхронные
ответы защищены поколением сессии. Смена API среды блокирует старый повтор.
Локальная форма сохраняется при сетевой ошибке, очищается при смене владельца.
Приватные фото загружаются по owner route с текущим Bearer, без постоянного
кэша и перенаправления Bearer на другой origin.

## Запуск и конфигурация

Подробные команды — `apps/mobile/README.md`. Разрешены ровно:

```text
API_BASE_URL=<согласованный доступный FastAPI URL с /api/v1>
SUPABASE_URL=https://pdjjdqgoitnkpgkbqjtp.supabase.co
SUPABASE_PUBLISHABLE_KEY=<публичный ключ проекта>
```

Вводятся в игнорируемом `apps/mobile/config/public.local.json` по шаблону.
Учебные учётные данные вводятся пользователем в форме; в APK/исходниках их нет.
Не использовать localhost другого разработчика. Не выполнять миграции/seed/
pytest против общей БД. Клиент не подключается к БД или Storage напрямую.

```powershell
cd apps/mobile
flutter pub get
flutter analyze
flutter test
flutter run --dart-define-from-file=config/public.local.json
./tool/build_android.ps1 -PublicConfig config/public.local.json
```
