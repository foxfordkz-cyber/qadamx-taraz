# Mobile: Flutter «Мал базар»

Шестой участник владеет `apps/mobile`. Создаёт Flutter-клиент общего `apps/api`, использует Supabase Auth и [LIVESTOCK_API](../../packages/contracts/LIVESTOCK_API.md). Не создаёт второй backend, собственную авторизацию или фиктивные memberships магазинов.

MVP: публичные лента/карточка, свои объявления, создание/редактирование, есть сегодня/продано/снять, до трёх фото, статистика цен предложений. RU/KZ, суммы int в тиынах, явное согласие на публикацию контакта. Не добавлять оплату, доставку, чат, аукцион или голос на этом этапе.

Показывать истёкшее «сегодня» по server available_today; смена аккаунта очищает приватные формы/cache, повтор неизвестного результата сохраняет ключ/тело. Фото отправляются основному API, никакого service key в приложении. Различать предложенный контракт, локально реализованный API и доступность общей среды.

Проверить Android emulator, физический телефон и RU/KZ; localhost телефона не является компьютером разработчика. Способы подключения и ошибки описаны в контракте. Передать реальные результаты в `docs/handoffs/mobile.md` при первой собственной реализации. Эта задача не создаёт Flutter-каркас вместо участника.
