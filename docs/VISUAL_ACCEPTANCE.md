## Что изменено и какие общие файлы затронуты

Всего 18 файлов кода и документации (без галереи):

- **Общий UI** (зона seller-web): `apps/web/src/shared/tokens.css` — только новые токены; `shared/styles.css`, `shared/merchant.css` — литералы цветов, радиусы, тени, нижние границы шрифта, disabled, выбор файла, высота выбора точки. Разметка и логика компонентов не менялись.
- **Аналитика** (зона seller-web): `features/seller/analytics/analytics.css` — только цвета через токены, без изменения разметки, данных и формул.
- **Витрина и 3D** (зона public-web/assets-3d): `features/explore/*` — токены и шрифт витрины, touch-цели, порядок карточек по маркерам, кадр и свет сцен, DOM-маркеры вместо drei `<Html>`, силуэты главной, раздел и сцена «Мал базар»; новые `SceneAnchors.tsx`, `sceneTokens.ts`, `MalBazar.tsx`, `MalBazarScene.tsx`.
- **Ассеты:** `apps/web/public/asset-sources.md` — происхождение схемы «Мал базар» и обзорных силуэтов. GLB, превью и `venue-assets.json` не менялись.

Не менялись: `apps/api`, миграции, OpenAPI, `generated.ts`, Auth, API-клиент, bindings/gateway, денежные формулы, идемпотентность, `features/voice`, маршруты и их имена, идентификаторы hotspot, `apps/mobile`, зависимости и lock-файлы.

### Исправлено на этапе D

Проверка D нашла дефект проектора из этапа C: сцены рисуют кадры только по требованию, поэтому якоря, пришедшие после последнего кадра (данные точек загрузились позже кэшированной модели), ждали следующего движения камеры. `Projector` теперь запрашивает кадр при изменении набора якорей (`SceneAnchors.tsx`).

## Ограничения

- GLB не пересобирались: пайплайну `tools/assets` нужен Blender 4.5 LTS, на рабочем ПК его нет. Улучшение силуэтов, вывесок и материалов самих моделей — следующий шаг assets-3d после установки.
- Web-ленты «Мал базар» нет: публичные `GET /livestock/*` уже есть в API 0.6.1, интеграция в web — отдельная задача владельца витрины/mobile; фиктивная лента не добавлялась.
- Названия учебных точек («Демо MART clothes») приходят из seed backend; RU/KZ названия — решение капитана.
- 48 мелких целей: логотипы и чекбокс пароля относятся к каркасу/входу seller-web.
