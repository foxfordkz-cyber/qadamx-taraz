# Qadam диплом research workspace

Бұл толық диплом мәтіні емес. Тақырып: «Жасанды интеллект технологиялары негізінде шағын бизнестің сатылымдары мен қарыздарын басқаруға арналған ақпараттық жүйені әзірлеу».

Алдымен [Source baseline](SOURCE_BASELINE.md), [Stage1 scope](STAGE_1_SCOPE.md), [алты кезең roadmap](IMPLEMENTATION_ROADMAP.md) және [ашық мәселелер](OPEN_ISSUES.md) оқылады.

- [01 — Research Foundation](01_Research_Foundation/research_passport.md): мақсат, RQ, әдебиет және scope.
- [02 — System Design](02_System_Design/architecture.md): нақты code modules, API/DB және7editableMermaid.
- [03 — Datasets and Experiments](03_Datasets_and_Experiments/evaluation_protocol.md): A–D protocol, provenance, actual vs missing results.
- [04 — Implementation Evidence](04_Implementation_Evidence/feature_evidence_matrix.md): feature/test/contribution/integration.
- [05 — Thesis and Defense](05_Thesis_and_Defense/thesis_outline_3_chapters.md): [25бет аралығы бойынша brief](05_Thesis_and_Defense/page_by_page_writing_plan.md), [ENU68талап](05_Thesis_and_Defense/university_compliance_matrix.md).

`evidence/...`, `tools/...` және workbook сілтемелері ZIP package түбіріне қатысты. Толық PDF/log/raw synthetic data және Excel package түбірінде сақталады. Репозиторийге көшірілген осы docs-only нұсқа application кодын өзгертпейді; негізгі таратылатын self-contained artifact — `Qadam_Diploma_Research_Workspace.zip`.

Ресми work/project жіктелімі, студенттің жеке үлесі, нақты бизнес/owner деректері және final student verification ашық. CSV/Excel статустары source/test scope-пен ғана өзгереді. Root-тағы төрт негізгі planning document осы docs-only көшірмеде де берілді; authoritative distributed package ішіндегі мазмұны бірдей.
