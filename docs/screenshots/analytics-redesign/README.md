Воспроизведение текущего вида из `apps/web`:

```sh
npm run test:e2e -- --config e2e/analytics-redesign.playwright.config.ts
npm run test:e2e -- --config e2e/analytics-layout.playwright.config.ts
npm run test:e2e -- --config e2e/assistant.playwright.config.ts
```

Набор проверяет 360/390/1440 px, размер текста 100%/200%, действия ≥44 px, отсутствие переполнения, разные ответы четырёх подсказок и прокрутку/фокус ответа на телефоне. Полный снимок включает фиксированную нижнюю навигацию на уровне текущего viewport.

Контраст текста на используемых светлых фонах: вторичные подписи `#58685f` — 5.31–5.84:1, фирменный зелёный `#164c3e` — 8.84–9.74:1. Итоговые проверки выполнены после merge `origin/main` e8f7b22.

Реальные устройства и production API этим набором не проверялись. Демо-число должников исправлено с прежнего фиктивного 8 на 3 существующих демо-клиента; их остатки 18 000 + 10 000 + 7 000 = 35 000 ₸. Денежные суммы карточек и графика не менялись.
