# Главная: обзор площадок — до и после

2026-10-17, роль №6. Слева `main` @ `1a541ef`, справа `feature/home-venue-showcase`. Одно окно Chrome с программным WebGL (SwiftShader). Локальный Vite читает публичный API Render только через GET; заголовок CORS для localhost добавлялся только в тестовом перехвате. Масштаб браузера эмулирован размером CSS-окна и devicePixelRatio: 1366×768 при 125 % = 1093×614, при 150 % = 911×512, при 200 % = 683×384.
