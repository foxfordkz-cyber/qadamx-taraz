# Презентационная полировка — до и после

2026-10-17, роль №6. Слева `deploy-062` = `main` @ `07197be`, справа ветка `feature/sale-debts-polish`. Один сценарий и одно окно Chrome для каждой пары: 1440 × 1000, 390 × 844, KZ 360 × 780.

**Кабинет продавца** — синтетические данные: локальный Vite, Supabase Auth и API перехвачены в браузере (точка «QA · Одежда · MART», клиенты «QA Клиент …», учебные продажи). Живой AI, общая БД и реальные аккаунты не использовались. На полностраничных снимках телефона нижнее меню скрыто, иначе при склейке оно попадает в середину страницы.

**Витрина** — локальный Vite читает публичный API Render только через GET; заголовок CORS для localhost добавлялся только в тестовом перехвате. Production и настройки сервера не менялись. 3D на снимках — программный WebGL; вариант «без WebGL» снят с отключённым WebGL.
