# Собираемость и возраст долгов — API 0.7.2

Синтетическое демо, без запросов к API. Новые карточки стоят после сводки и списка напоминаний, перед дневным графиком. В каждом изображении сохранены текущие суммы основной аналитики.

| Язык / ширина | Вся страница | Две новые карточки |
|---|---|---|
| RU · 390 | [Страница](ru-390.png) | [Карточки](cards-ru-390.png) |
| KZ · 390 | [Страница](kk-390.png) | [Карточки](cards-kk-390.png) |
| RU · 1440 | [Страница](ru-1440.png) | [Карточки](cards-ru-1440.png) |
| KZ · 1440 | [Страница](kk-1440.png) | [Карточки](cards-kk-1440.png) |

У полной страницы viewport 1000 px по высоте; фиксированная нижняя навигация отражена на уровне viewport. Для отдельного снимка карточек высота viewport увеличена при необходимости, чтобы реальные закреплённые шапка и навигация не перекрывали блок. Элементы приложения не скрывались и не перерисовывались для снимков.

Демо за 7 дней: 43 000 + 8 000 + 23 000 = 74 000 ₸, собрано 51 000 ₸ (69%). За 30 дней: 220 000 + 48 000 + 32 000 = 300 000 ₸, собрано 268 000 ₸ (89%). Возраст всех открытых долгов для обоих периодов: 23 000 + 9 000 + 3 000 = 35 000 ₸, 3 / 2 / 1 продажа. Собираемость относится к продажам периода; она не подменяется поступлениями за период.

Проверены RU/KZ, ширины 360/390/1440, текст 100%/200%, отсутствие горизонтального переполнения, текстовые альтернативы всех четырёх полос, кнопка ≥44 px, переход к напоминаниям с фокусом на компьютере и к долгам на телефоне. В старом API при null/отсутствии полей карточки скрыты; при нулевых данных показаны явные пустые состояния.

Воспроизведение из `apps/web`:

```sh
npm run test:e2e -- --config e2e/analytics-redesign.playwright.config.ts
npm run test:e2e -- --config e2e/analytics-layout.playwright.config.ts
```

Новый файл `e2e/analytics-collection.acceptance.ts` входит в конфигурацию redesign. `QADAM_SCREENSHOT_ROOT` позволяет сохранить снимки прежних regression-тестов отдельно; новая галерея сохраняется в этом каталоге. Это браузерная проверка с моками, не приёмка production API на физическом телефоне.
