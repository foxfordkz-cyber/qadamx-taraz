## Проверенная серверная конфигурация

Существующий адаптер/`.env.example`/OPENAI_DEFENSE_READINESS задают:

```dotenv
AI_PROVIDER=openai
OPENAI_MODEL=gpt-6-luna
OPENAI_TRANSCRIPTION_MODEL=gpt-transcribe
AI_FALLBACK_OPENAI=false
```

`OPENAI_API_KEY` вводится только в Render Environment; значение здесь отсутствует. Старые AI_API_KEY/AI_MODEL сохранить для отката, в OpenAI-primary они не используются. AI_PRIMARY_TIMEOUT_SECONDS=8 относится только к отключённому fallback. Общий deadline25с, output cap2048, `reasoning.effort=none` для gpt-6-luna, `max_attempts=1`, автоматического HTTP retry нет. Mini STT не выбран. Официальный контракт STT возвращает поле text: [file transcription](https://developers.openai.com/api/docs/guides/speech-to-text); [Responses](https://developers.openai.com/api/reference/resources/responses/methods/create).

Активный OpenAI/gpt-transcribe подтверждён логом капитана. Точное имя **активной модели извлечения**, значение fallback и новый deployment SHA публичный ответ DraftResponse не раскрывает: выше указана подготовленная конфигурация, не недоступный снимок Render Environment. Для окончательной фиксации нужны запись `openai_extraction` одного успешного request_id и deployment details, без секретов. Успешное получение draft не заменяет эту проверку.
