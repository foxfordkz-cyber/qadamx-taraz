## Резервное видео: сценарий 75–90 секунд

Запись экрана должна явно показывать «Учебная демонстрация». Не показывать пароли,
токены, чужие клиентские данные и панели Environment. До записи согласовать одну
учебную точку и клиента. Эта подготовка сама денежных операций не создаёт.

| Время | Кадр и объяснение |
| --- | --- |
| 0–10 с | Сайт и задача: продажи, оплаты и долги небольшого магазина; RU/KZ. |
| 10–25 с | Учебная точка, ручная форма: продажа 3000 ₸, оплачено 1000 ₸. Клиента выбирает человек. |
| 25–40 с | Явное подтверждение; показать созданную продажу и долг 2000 ₸. При неизвестном результате сначала история/recovery, не новая операция. |
| 40–55 с | Доплата 500 ₸: остаток 1500 ₸; продажи остаются 3000 ₸, поступления всего 1500 ₸. |
| 55–70 с | История и аналитика: сравнение с исходными значениями, reload сохраняет данные. |
| 70–85 с | Главная → площадка → магазин; учебные модели обозначены. QR сайта. |

Если новые записи не согласованы, показать уже существующие учебные операции
или подписанную схему расчёта. Не изображать нажатие на заглушку как живую запись.
Для AI достаточно объяснить: черновик → проверка → подтверждение; платный запрос
ради видео не повторять. При сбое использовать ручной ввод.

## Ограничения, которые нужно сказать честно

- Email-регистрация на Pages прошла совместную живую приёмку: письмо, новая сессия, reload и повторный вход прежнего аккаунта. [Версии и ограничения](../REGISTRATION_PAGES_LIVE_20261017.md). Новый аккаунт сам по себе не получает торговую точку; для демонстрации учёта используйте существующий учебный аккаунт.
- iPhone/Safari, настоящий микрофон и APK требуют отдельной физической проверки.
- Мал базар: справочник подтверждённых рынков пуст; нет вымышленных реальных цен.
- Render Free может просыпаться после простоя. Дождаться ответа, не нажимать повторно на запись с неизвестным результатом.
- Исходный recording.webm отсутствует: тот инцидент не закрыт другим аудио.
