# Визуальный аудит и направление — этап A

2026-10-16. Ветка `feature/unified-visual-3d` от `integration/seller-analytics-061` @ `1324885` (наследник проверенной сборки `5ab11b1`, PR #18; отличие только в документации). Передача роли — [handoffs/visual-3d.md](handoffs/visual-3d.md).

## Как проводился аудит

Запущенное приложение этой ветки, локальный Vite `127.0.0.1:5188`. Публичные страницы получали настоящие публичные данные через временный HTTPS API команды из [FLUTTER_CONNECTION](FLUTTER_CONNECTION.md), только GET. Кабинет продавца — явный read-only Demo, вход не выполнялся, все не-GET запросы к API блокировались скриптом обхода.

13 страниц × 4 ширины (1440, 768, 390, 360): главная, площадка MART, магазин `mart-demo-home`, вход, главная кабинета, продажа, «Мне должны», история, итог дня, аналитика, заявки, клиенты, каталог. Для каждой страницы замерены горизонтальное переполнение, интерактивные элементы меньше 44 px и набор фактических размеров шрифта, собраны ошибки консоли и ответы 4xx/5xx. Headless Chrome с программным WebGL, не физический телефон.

## Направление

Сохраняются узнаваемость Qadam и Manrope: paper, ink, зелёный, lime для главного действия, orange для вторичных акцентов. Витрина выразительнее (крупный заголовок, 3D, превью), кабинет спокойный и плотный. Один набор токенов в `shared/tokens.css`, локальные имена модулей только ссылаются на него.

Добавленные токены:

- Поверхности и линии: `--qadam-surface-muted`, `--qadam-line-strong`, `--qadam-scene-sky`.
- Статусы, всегда вместе с текстом или иконкой: `--qadam-success|warning|danger|info` и `*-soft` подложки.
- Типографика: 12 / 14 / 16 / 20 / 28 и display (`--qadam-text-*`). Деньги — `tabular-nums`, формат прежний.
- Элементы: `--qadam-control-height: 44px`, `--qadam-radius-small: 8px`, `--qadam-focus-ring`, `--qadam-shadow-raised`, `--qadam-content-width`.
