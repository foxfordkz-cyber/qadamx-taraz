## Backend и публикация

`apps/api` и `packages/contracts` побайтово совпадают с `8f1764d`; backend, зависимости и запуск не менялись. Не требуется Manual Deploy Render. Не менялись Environment, CORS, Supabase, memberships, миграции или seed. Платных AI-вызовов и записей в общую БД нет.

Синхронизация Git выполняется только fast-forward, без force push, после проверки актуальных remote heads. Автоматический Vercel deployment нужно подтвердить отдельно по событию SHA и фактически загружаемым файлам. При build-rate-limit не запускать повторные сборки циклически.
