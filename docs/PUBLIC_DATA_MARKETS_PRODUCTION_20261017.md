2. Выполнено настоящее восстановление в отдельную локальную PostgreSQL: отпечатки
   всех 13 исходных таблиц совпали. Затем применены 0007/0008 и проверена совместимость.
3. В окне выпуска Render приостановлен; получена свежая копия и повторено восстановление
   в другую отдельную БД. Частичные неудачные попытки backup не использовались.

   Memberships, исходные ACL и RLS сохранены. Registry пуст, старые market_id — null.

Локальное восстановление использовало `--no-owner --no-acl`; это не репетиция
восстановления Supabase Auth/Storage. Оригинальные ACL сохранены в метаданных копии,
а их неизменность в общей БД проверена отдельно. Backup и Environment хранятся
локально в игнорируемом каталоге и не опубликованы в GitHub.

Сравнены 59 прежних GET-ответов старого защищённого API и API 0.6.3 на восстановленной
